# RF06 — Consultar inadimplentes

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Administrador

## Descrição
O sistema deve permitir consultar alunos inadimplentes.

## Implementação
- API: `GET /api/inadimplentes` em [`server.js`](../../../../server.js), `adminOnly`. Regra: aluno ativo **sem** pagamento `Pago` para a `referencia_mensal` do mês corrente.
- Query de referência também em [`sql/03_queries.sql`](../../../../sql/03_queries.sql) (versão estendida considerando `Pendente` vencido e `Atrasado`).
- Frontend: [`public/js/inadimplentes.js`](../../../../public/js/inadimplentes.js).

## Testes
- SQL: [`sql/04_tests.sql`](../../../../sql/04_tests.sql) — "RF06 lista inadimplentes" garante ≥ 1 linha com o seed.
- API: [`tests/api.test.js`](../../../../tests/api.test.js) — Aluno não acessa (403); Admin recebe lista.
