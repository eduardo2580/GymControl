# RF01 — Cadastro de alunos

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Administrador

## Descrição
O sistema deve permitir o cadastro de alunos.

## Implementação
- Schema: [`sql/01_schema.sql`](../../../../sql/01_schema.sql) — tabela `alunos` com `nome`, `cpf` (UNIQUE), `telefone`, `data_nascimento`, `status`, `plano_id`, `data_inicio_plano`, `observacoes`.
- API: `POST /api/alunos` em [`server.js`](../../../../server.js), restrito a Admin via `adminOnly`.
- Validação de CPF (formato + dígito verificador) em [`lib/validators.js`](../../../../lib/validators.js) `isValidCpf`.
- Frontend: [`public/js/alunos.js`](../../../../public/js/alunos.js) — `openModalCadastrarAluno` + `salvarAluno`, com máscara de CPF/telefone aplicada via `maskCpfInput`/`maskPhoneInput` em [`core.js`](../../../../public/js/core.js).

## Testes
- API: [`tests/api.test.js`](../../../../tests/api.test.js) — POST com CPF válido, sem máscara, e cenários de erro.
- E2E: [`tests/e2e/app.spec.js`](../../../../tests/e2e/app.spec.js) — fluxo "cadastrar, editar e remover aluno" com máscara automática.
