# RF04 — Cadastro de planos

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Administrador

## Descrição
O sistema deve permitir o cadastro de planos da academia.

## Implementação
- Schema: tabela `planos` com `nome`, `valor` (CHECK ≥ 0), `duracao_meses` (CHECK > 0), `descricao` — ver [`sql/01_schema.sql`](../../../../sql/01_schema.sql).
- API: `GET/POST/PUT/DELETE /api/planos` em [`server.js`](../../../../server.js); mutações sob `adminOnly`. GET é público para qualquer autenticado (necessário no cadastro de aluno).
- Frontend: [`public/js/planos.js`](../../../../public/js/planos.js).

## Testes
- API: [`tests/api.extra.test.js`](../../../../tests/api.extra.test.js) — bloco "PLANOS - CRUD completo" inclui RBAC (aluno não cria, admin cria/atualiza/deleta).
- SQL: [`sql/04_tests.sql`](../../../../sql/04_tests.sql) — CHECK valor ≥ 0.
