# RF03 — Cadastro de professores

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Administrador

## Descrição
O sistema deve permitir o cadastro de professores.

## Implementação
- Schema: tabela `professores` com `nome`, `cref` (UNIQUE), `especialidade`, `telefone`, `email` — ver [`sql/01_schema.sql`](../../../../sql/01_schema.sql).
- API: `GET/POST/PUT/DELETE /api/professores` em [`server.js`](../../../../server.js); mutações sob `adminOnly`.
- Frontend: [`public/js/professores.js`](../../../../public/js/professores.js).

## Testes
- API: [`tests/api.extra.test.js`](../../../../tests/api.extra.test.js) — bloco "PROFESSORES - PUT e DELETE" cobre criação, atualização e remoção.
- SQL: [`sql/04_tests.sql`](../../../../sql/04_tests.sql) valida UNIQUE em `cref`.
