# Documentação

## 🎓 [Tutoriais](tutorials/)
Guias passo a passo de Docker, Playwright e MySQL aplicados ao projeto.

---

A documentação técnica está dividida em duas entregas:

## 📌 [Entrega parcial](entrega-parcial/)
Documento original entregue na primeira fase da disciplina — apenas planejamento (UML, RFs/RNFs, tecnologias, cronograma, orçamento). **Arquivada e congelada**, não atualizar.

## 🚧 [Entrega final](entrega-final/)
Documentação viva da fase final, incluindo o sistema implementado: o status de cada RF/RNF, mapeamento código ↔ requisito, casos de uso, classes, e tudo o que foi adicionado além do escopo original (autenticação, segurança, testes, CI/CD).

Para acrescentar novas funcionalidades, novos requisitos ou novos casos de uso, escreva em [`entrega-final/`](entrega-final/) — **não** edite a pasta `entrega-parcial/`.

Comece por [`entrega-final/INDEX.md`](entrega-final/INDEX.md).
