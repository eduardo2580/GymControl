# RF07 — Cadastro de treinos

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Professor (e Administrador)

## Descrição
O sistema deve permitir o cadastro de treinos.

## Implementação
- Schema: tabela `treinos` (`aluno_id`, `professor_id`, `objetivo`, `data_inicio`, `data_fim`, `nivel` ENUM, `observacoes`) + tabela `exercicios` (1..N, com `ordem`, `series`, `repeticoes`, `descanso_seg`) — ver [`sql/01_schema.sql`](../../../../sql/01_schema.sql).
- A relação 1..N treino → exercício é uma escolha estrutural além do docx (lá `Exercicio` aparece como classe mas não como tabela). Mantém a semântica de QUADRO 9.
- API: `POST/PUT/DELETE /api/treinos` em [`server.js`](../../../../server.js), com middleware `adminOrProf`. PUT substitui exercícios via `replaceExercicios`.
- Frontend: [`public/js/professor.js`](../../../../public/js/professor.js).

## Testes
- API: [`tests/api.extra.test.js`](../../../../tests/api.extra.test.js) — bloco "TREINOS - update e delete": cria com 2 exercícios, atualiza substituindo por 1, valida RBAC (aluno não deleta).
