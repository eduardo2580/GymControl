# RF09 — Registrar frequência

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Administrador

## Descrição
O sistema deve permitir registrar a frequência dos alunos.

## Implementação
- Schema: tabela `frequencias` com `aluno_id` (FK), `data_entrada`, `horario_entrada`, `horario_saida` — ver [`sql/01_schema.sql`](../../../../sql/01_schema.sql). Índices em `(aluno_id, data_entrada)` e `data_entrada`.
- API: `GET/POST/DELETE /api/frequencia` em [`server.js`](../../../../server.js); mutações `adminOnly`.
- Frontend: [`public/js/frequencia.js`](../../../../public/js/frequencia.js) (admin) + visualização em [`public/js/aluno.js`](../../../../public/js/aluno.js) (`renderAlunoFrequencia`).

## Testes
- API: [`tests/api.extra.test.js`](../../../../tests/api.extra.test.js) — bloco "FREQUÊNCIA" (POST por admin, 403 para professor, filtro por aluno, DELETE).
