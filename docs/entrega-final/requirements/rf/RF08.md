# RF08 — Vincular treinos a alunos

**Tipo:** Requisito funcional
**Status:** ✅ Implementado
**Atores:** Professor

## Descrição
O sistema deve permitir vincular treinos aos alunos.

## Implementação
- O vínculo é direto no schema: `treinos.aluno_id` é FK obrigatória para `alunos.id` (ver [`sql/01_schema.sql`](../../../../sql/01_schema.sql)). Cada treino criado já carrega o aluno associado.
- API: campo `alunoId` obrigatório no `POST /api/treinos`. O Aluno pode consultar seus treinos via `GET /api/treinos?alunoId=...`.
- Frontend: o professor seleciona o aluno na modal de criação (ver [`public/js/professor.js`](../../../../public/js/professor.js)).

## Testes
- API: cobertura junto ao RF07 — todo treino de teste é criado com `alunoId: 1`. Filtro por `alunoId` validado em [`tests/api.extra.test.js`](../../../../tests/api.extra.test.js) (bloco "FREQUÊNCIA" usa o mesmo padrão).
